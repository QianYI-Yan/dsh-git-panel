## 主要变更

- **面板入口位置可配置**：新增「Git 面板入口位置」设置——「标签页和侧边栏 / 仅标签页 / 仅侧边栏」，可以把 Git 面板放进界面右侧边栏、与对话并排看 diff，保存后立即生效（#62、#77）
- **手机与窄侧边栏的总览改为抽屉排布**：手机屏幕（短边 ≤640 且主指针为触摸）的侧边栏不再套桌面的上下两带排布，横屏即正常三栏，stacked 只留给桌面；窄侧边栏与手机的总览左栏收进分支抽屉，点空白 / 关闭按钮 / Esc 收起，选完分支自动合上
- **移动端交互不再留尾巴**：输入法弹出不再把正在输入的提交编辑器折叠掉；触摸不会升起悬停提示（此前点一下就永久挡着界面）；触摸设备上图标按钮命中区放大到 34×34（#81）
- **文件预览更顺手**：点文件名即复制相对路径；新增「复制文件内容」按钮；空目录展开显示「空目录」提示行；超长行完整显示不再截断；文本选区不再被虚拟滚动清掉
- **SVG 预览可切源码**：预览能在渲染与源码视图间切换并复制源码；超过 4 MiB 图片上限的 SVG 改按源码下发，不再报「文件过大」（#81）
- **界面细节统一**：插件图标换成新稿，差分区与弹窗的图标按钮统一为带框样式，返回按钮文案统一「返回」，窄面板状态栏隐藏 GitHub 仓库图标
- **修复**：分支抽屉补齐对话框契约——Tab 不再跑进遮罩后面，Esc 让给上层弹窗，焦点在开合之间往返（#81）
- **修复**：缩放桌面不再被误判成手机（1366×768 在 125% 缩放下的短边只有 614px），右侧边栏恢复 stacked 排布与分割线拖拽（#81）
- **修复**：`maxBytes` 配置夹取到 64 KiB–64 MiB，笔误不再能把面板整个关掉；行号列默认 3 位宽、超过 3 位再自增，空数据面板不再多出一条滚动条，根级文件名也能省略并出 hover 下划线（#81）
- **内部**：千行 client 模块拆成样式表 / diff 区 / 文件预览三个文件并抽出 useHtmlPreview（#80）；空目录提示补上断言，CI 的行高与行号断言改为按实测字体度量，Linux runner 不再随机转红（#81）

## English

- **Configurable panel placement**: a new "Git panel entry location" setting — "Tab and sidebar / Tab only / Sidebar only" — lets you put the Git panel in the right sidebar to view diffs alongside the chat; saved changes apply immediately (#62, #77)
- **Sidebar and overview rebuilt for phones and narrow rails**: on phone screens (short edge ≤ 640 with a coarse pointer) the sidebar no longer uses the desktop stacked bands — landscape gets the normal three columns, stacked stays desktop-only; on narrow rails and phones the overview's left column moves into a branch drawer that closes on scrim click / close button / Esc and auto-closes after picking a branch
- **Mobile interactions no longer leave artifacts**: the IME popping up no longer folds the commit editor you are typing into; taps no longer raise hover tips (one tap used to leave one stuck on screen forever); icon buttons get a 34×34 touch target on touch devices (#81)
- **Nicer file preview**: click a file name to copy its relative path; a new "copy file content" button; expanded empty directories show an "Empty directory" row; overlong lines render in full instead of being truncated; text selection survives virtual scrolling
- **SVG preview can show source**: switch between rendered and source views and copy the source; SVGs above the 4 MiB image cap are served as source instead of failing as "too large" (#81)
- **Unified interface details**: a redesigned plugin icon, bordered icon buttons in the diff pane and dialogs, a consistent "Back" label on narrow screens, and the GitHub repo icon hidden from the narrow status bar
- **Fix**: the branch drawer now honors the dialog contract — Tab no longer walks behind the scrim, Esc yields to dialogs above, and focus travels back and forth across open/close (#81)
- **Fix**: a scaled desktop is no longer mistaken for a phone (1366×768 at 125% scale has a 614px short edge), so the right sidebar keeps its stacked layout and band resizer (#81)
- **Fix**: `maxBytes` is clamped to 64 KiB–64 MiB so a typo can no longer disable the panel; line numbers default to 3 digits and widen only when needed, empty panels no longer grow a stray scrollbar, and root-level file names ellipsize with the hover underline too (#81)
- **Internal**: the thousand-line client module is split into styles / diff pane / file preview with `useHtmlPreview` extracted (#80); empty-directory hints gained assertions, and the CI line-height / line-number assertions now measure real font metrics so Linux runners stop flipping red at random (#81)
