## 主要变更

- **AI 生成提交信息支持固定模型**：详情页可从 DSH 模型列表按「提供方 → 模型 → 推理强度」三级级联为 AI 生成固定一个专属模型，**默认跟随当前会话**；不选推理强度时用模型默认值（#54）
- **文件源码预览支持自动换行**：源码视图默认把长行折入可视宽度，可一键关掉换行改横向滚动查看完整长行；超过 2000 行或 1 MiB 的大文件仍走行虚拟化的横向滚动，不拖垮首屏（#59）
- **文件浏览 Markdown 预览增强**：内嵌的本地图片（如 README 配图）直接显示，`<kbd>` 提示渲染为行内代码，```mermaid 代码块渲染为图表、解析失败回退代码块（#55）
- **修复**：固定模型路由真正生效——此前配置页选了固定模型仍走会话模型、模型下拉恒显示「未检测到可用模型」（volatile 配置解包与模型目录方法绑定两处）（#54）
- **修复**：文件被删除后再点预览，提示「文件不存在（可能已被删除或移动）」，不再是笼统的「加载失败」
- **内部**：构建产物 `lib/` 移出仓库，出厂产物改由发布 workflow 的 `npm pack` 生成并校验；新增 GitHub Actions 发布流程（完整门禁 → 打 tag → 预发布 / 正式版分流），npm Trusted Publishing 已就绪；dsh 运行时 peer 标记为可选

## English

- **AI commit messages can pin a model**: on the plugin detail page, cascade-select a dedicated model (provider → model → reasoning effort) from the DSH model list for AI-generated commit messages, **following the current session by default**; with no effort picked, the model default applies (#54)
- **Word wrap in the source preview**: the source view now wraps long lines into the visible width by default; toggle it off to scroll long lines horizontally instead. Files over 2000 lines or 1 MiB keep the virtualized horizontal-scroll grid so the first paint stays fast (#59)
- **Richer Markdown preview in the file browser**: embedded local images (e.g. README figures) render inline, `<kbd>` hints become inline code, and ```mermaid fences render as diagrams with a code-block fallback (#55)
- **Fixes**: the pinned model route now actually takes effect — previously a pinned model still fell back to the session model and the model dropdown always read "no models detected" (two root causes: volatile config unwrapping and detached model-catalog method calls) (#54)
- **Fixes**: previewing a file that was deleted afterwards now says "File not found (deleted or moved)" instead of a generic "Load failed"
- **Internal**: build output `lib/` moved out of the repository — the shipped artifacts are now produced and asserted by the release workflow's `npm pack`; new GitHub Actions release pipeline (full gate → tag → prerelease/formal split), npm Trusted Publishing ready; the dsh runtime peer is now optional
