## 主要变更

- **修复**：侧边栏「开始」页的 Git 卡片图标与顶部 Git chip 图标不再偶发整只消失——插件图标的渐变改为每实例独立定义并带兜底描边色，任何一份副本卸载都不会再让可见图标的笔画一起失效（#88）

## 安装

```bash
# 正式版（npm）
dsh plugin --profile web add @xbzbing/dsh-git-panel@1.9.4

# 同一版本的 GitHub Release 附件
dsh plugin --profile web add https://github.com/xbzbing/dsh-git-panel/releases/download/v1.9.4/xbzbing-dsh-git-panel-1.9.4.tgz
```

## 验证

- `npm run check` 全绿：typecheck + 664 单测 + 22 个 e2e runner + 产物一致性
- 图标渐变回归（#88）：e2e 在同一文档渲染两份插件图标，断言渐变 id 互异、各自描边引用自身 id 且携带 fallback 色；把渐变 id 改回固定值即转红

## English

- **Fixes**: the plugin icon on the sidebar start page's Git card and on the Git chip no longer vanishes entirely at random — the glyph's gradient is now defined per instance with a fallback stroke colour, so unloading any one copy can no longer take the visible copies' strokes down with it (#88)

## Install

```bash
# Stable (npm)
dsh plugin --profile web add @xbzbing/dsh-git-panel@1.9.4

# The same version as a GitHub Release asset
dsh plugin --profile web add https://github.com/xbzbing/dsh-git-panel/releases/download/v1.9.4/xbzbing-dsh-git-panel-1.9.4.tgz
```

## Verification

- `npm run check` green: typecheck + 664 unit tests + 22 e2e runners + built-artifact consistency
- Icon-gradient regression (#88): an e2e renders two glyph copies in one document and asserts their gradient ids differ, each stroke references its own id, and a fallback colour is carried; putting the gradient id back to a fixed value turns it red
