## 主要变更

- **界面支持八种语言**：除中、英外，新增 dsh 0.2.2 的日、西、法、德、俄、葡六种界面语言；dsh 未内置的语言回落到英文（#90）
- **插件详情页按界面语言显示 README**：英文界面显示英文 README，中文界面显示中文 README，其他语言显示英文；README 里的截图在详情页也能正常显示（#90）
- **修复**：手机窄屏下「Git」收进了「更多会话视图」菜单，点击输入框标记没有反应；现在会经菜单切到 Git，再点一次回到对话（#90）
- **修复**：AI 生成提交信息时，会话模型服务晚于插件启动或被重启后，读不到当前会话选的模型；现在每次生成都重新读取（#90）

## 安装

```bash
# 正式版（npm）
dsh plugin --profile web add @xbzbing/dsh-git-panel@1.9.5

# 同一版本的 GitHub Release 附件
dsh plugin --profile web add https://github.com/xbzbing/dsh-git-panel/releases/download/v1.9.5/xbzbing-dsh-git-panel-1.9.5.tgz
```

## 验证

- `npm run check` 全绿：typecheck + 671 单测 + 22 个 e2e runner + 产物一致性
- 手机窄屏切换：e2e 模拟「Git 收在菜单里、菜单延迟弹出」，断言点击标记会打开菜单、选中 Git、菜单关闭，再点一次回到对话；撤掉修复后该场景转红
- 详情页与多语言：契约单测要求每份 `locale/*.json` 都进 `package.json` 的 `exports`、`meta.detail` 指向的文件存在、README 图片只用 https 地址或随包文件；词典单测要求六种语言与英文键集、占位符一致。另在隔离的 dsh 0.2.2-alpha.2 实例上，用打包产物实测详情页的中、英、日三种语言和 7 张截图

## English

- **Eight UI languages**: besides Chinese and English, the panel now ships the six UI languages dsh 0.2.2 adds (Japanese, Spanish, French, German, Russian, Portuguese); languages dsh has no dictionary for fall back to English (#90)
- **The plugin detail page shows the README in the UI language**: English UIs get the English README, Chinese UIs the Chinese one, and other languages the English one; the README screenshots now load on the detail page too (#90)
- **Fixes**: on narrow phone layouts, where "Git" sits in the "More conversation views" menu, tapping the input-bar marker did nothing; it now switches to Git through that menu, and a second tap returns to the conversation (#90)
- **Fixes**: AI commit-message generation could not read the session's chosen model when the session model service started after the plugin or was restarted; it is now read on every request (#90)
