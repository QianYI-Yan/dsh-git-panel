## 主要变更

- **Git 标签状态点回到标签名右侧**：dsh 0.2.1-rc.3 里状态点掉到标签名下方、还把整排标签撑高——现在圆点画在名字右侧同一行，标签行高度与其余标签一致（#84）
- **全屏被拒改为面板内提示**：浏览器拒绝全屏请求时，全屏阅读器内显示可关闭的提示条（`role=status`，读屏可播报），不再只有打开控制台才看得见
- **侧栏标签页标题带上应用图标**：右侧栏「Git」标题前渲染插件图标，与平台自带标签视觉一致；标题被裁剪时图标不会被压缩

## 安装

```bash
# 正式版（npm）
dsh plugin --profile web add @xbzbing/dsh-git-panel@1.9.2

# 同一版本的 GitHub Release 附件
dsh plugin --profile web add https://github.com/xbzbing/dsh-git-panel/releases/download/v1.9.2/xbzbing-dsh-git-panel-1.9.2.tgz
```

## 验证

- `npm run check` 全绿：typecheck + 664 单测 + 22 个 e2e runner + 产物一致性
- 状态点回归（#84）：e2e 量测圆点与标签名的盒模型，要求圆点落在名字右侧且与名字同线、标签行高度不被撑高；把注入点改回按钮，两条断言立即转红
- 全屏回归：e2e 断言 `requestFullscreen` 被拒时提示条出现（`screenFullRefused`）、真正进入全屏后消失（`screenFullGranted`）

## English

- **The Git tab status dot is back beside the tab name**: under dsh 0.2.1-rc.3 the dot dropped below the name and stretched the whole tab row — it now sits on the name's own line, and the row keeps the same height as its neighbours (#84)
- **A refused full screen is now reported in the panel**: when the browser turns down `requestFullscreen`, the reader shows a dismissible notice bar (`role=status`, announced by screen readers) instead of only a console line
- **The sidebar tab title carries the plugin icon**: the right-sidebar "Git" title renders the plugin glyph ahead of it, matching the platform's own chips, and the icon no longer shrinks when the title is clipped

## Install

```bash
# Stable (npm)
dsh plugin --profile web add @xbzbing/dsh-git-panel@1.9.2

# The same version as a GitHub Release asset
dsh plugin --profile web add https://github.com/xbzbing/dsh-git-panel/releases/download/v1.9.2/xbzbing-dsh-git-panel-1.9.2.tgz
```

## Verification

- `npm run check` green: typecheck + 664 unit tests + 22 e2e runners + built-artifact consistency
- Status-dot regression (#84): an e2e measures the boxes of the dot and the tab name — the dot must sit to the right of the name on its own line and the row must keep its height; moving the injection point back to the button turns both assertions red at once
- Full-screen regression: an e2e asserts the notice appears when `requestFullscreen` is refused (`screenFullRefused`) and disappears once a request is granted (`screenFullGranted`)
