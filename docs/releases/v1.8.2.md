## 主要变更

- **分支名与目录同名时历史不再空白**：当工作区里有与分支同名的已跟踪目录或文件时（例如 `observatory/` 与分支 `observatory`），点击该分支现在能正常列出提交；默认「全部分支」视图遇到名为 `HEAD` 的文件也不会整页空白（#78、#79）
- **筛选失败不再静默**：真实的 `ambiguous argument` 会返回错误并在面板显示「加载失败」，只有未知或已删除的 ref 才按空历史处理（#79）

## 安装

```bash
# 正式版（npm）
dsh plugin --profile web add @xbzbing/dsh-git-panel@1.8.2

# 同一版本的 GitHub Release 附件
dsh plugin --profile web add https://github.com/xbzbing/dsh-git-panel/releases/download/v1.8.2/xbzbing-dsh-git-panel-1.8.2.tgz
```

## 验证

- `npm run check` 全绿：lint + typecheck + **614** 单测 + **20** 个 e2e runner
- 同名分支/目录：真实 git 回归用例在去掉 `--` 后会以 `fatal: ambiguous argument ... both revision and filename` 转红，修复后列表与总数都正确；名为 `HEAD` 的默认视图用例同样覆盖
- 错误映射：歧义 stderr 用例断言返回 `git-error` 而不是空页

## English

- **History no longer goes blank when a branch shares its name with a directory**: when the work tree contains a tracked directory or file with the same name as a branch (for example `observatory/` and branch `observatory`), clicking that branch now lists its commits instead of an empty page; the default all-branches view also survives a file named `HEAD` (#78, #79)
- **A failed filter is no longer silent**: a real `ambiguous argument` returns an error and the panel shows "Load failed"; only an unknown or deleted ref is still treated as an empty history (#79)
