## 主要变更

- **变更列表支持批量选择**：暂存 / 变更 / 未跟踪三组表头各带一个全选框，一次点选整组；工具栏新增「放弃全部」，确认后由宿主重跑 status 再执行，只清工作区、不动暂存区，状态流被截断时直接拒绝而不是悄悄放弃一个前缀。列表被截断时提供「展开全部」（上限 1 万条），展开后保持完整、不会被下一轮轮询裁回（#60）
- **没有远程分支时可以直接发布分支**：远程分支还不存在的仓库，推送按钮变为「发布」——一次 `git push -u <远程> HEAD` 建分支并设置上游，不必回终端手敲；游离 HEAD 或尚无提交的分支会明确拒绝并给出原因，动作始终不带 `--force`（#63）
- **折叠只在「窄且矮」时发生**：宽度 ≤620px 才切为单栏钻取布局；折叠提交编辑器、隐藏变更与提交时间需要宽度 ≤620 **且** 高度 ≤520 同时成立。打开右侧边栏把面板压窄、或大屏手机上，只要高度够就保留完整编辑器与时间；窄而高时时间落到统计条第二行，折叠条上的 AI 入口照旧（#66）
- **界面细节**：变更行的「放弃」改用统一的垃圾桶图标（原箭头容易被读成刷新），禁用的按钮也能弹提示、触摸屏点一下即收起；紧凑布局的子页签改用短标签（Git / 变更 / 文件）；面板字号 A−/A/A+ 改存宿主配置，跨会话保持（#61）
- **HTML 预览能加载相对引用的样式与脚本**：预览在隔离 iframe 内按文档相对路径读出同目录的 css / js 并内联进文档，设计稿不再是无样式的裸 HTML；限额为单资源 4 MiB、整包 32 MiB、最多 64 个，任一失败整体回退原始字节，sandbox 不变（#67）
- **文件浏览新增悬浮刷新按钮**：目录树右上角常驻一个刷新入口，点一下重新拉取当前目录；刷新期间旧目录的响应不会再覆盖新列表（#74）
- **HTML 预览不再冻结面板**：交互预览的 iframe 改用 `blob:` URL 加载，Chromium 给它独立渲染进程——同一份 1.25 MB 报告以前会把整个 GUI 卡住约 12 秒（父页面冻结 12,064 ms，现在 32 ms）；渲染期间预览区盖一层加载遮罩，由页面自己回报就绪后淡出（#75）
- **全屏阅读器复用已渲染的预览**：点「放大」打开的阅读器直接把已在渲染的预览换成全屏样式，不重建 iframe——页面脚本不重跑，代码视图的滚动位置与查找状态也不丢；标题栏关闭按钮左侧新增浏览器全屏开关（#75）
- **重页面的等待现在可预期、可退出、可绕开**：渲染遮罩 4 秒后放行点击并显示已等待秒数，给出「停止渲染」直接回到源码视图；内联脚本超过 512 KiB 的文档在挂载前先用弹窗问一次（取消 / 仍然渲染）；本地实例还能选「在系统浏览器中打开」，远程实例则说明文件在远端、只能内嵌渲染（#76）
- **修复**：AI 生成提交信息在 OpenCode 路由上固定报 400 `MissingSessionID`——现在只有 provider 名含 OpenCode（忽略大小写）时才注入会话标识，其余路由不再多带会话归属元数据，生成失败的横幅也新增了关闭按钮（#71）；提交失败文案改为本地化、错误横幅单行垂直居中；加载指示统一换成平台的 `StateDot` 动效，自绘圆环不再露接缝
- **内部**：发布正文只归档正式版（`docs/releases/`），预发布页面照写但不入库；正式版对比基线取上一个正式版 tag、安装段正式版给 npm + 附件而预发布只给附件，这几条规则由 `release-notes.test.mjs` 逐版校验；README 增加致谢章节（#73）

## English

- **Batch selection in the changes list**: the staged / changes / untracked group heads each carry a select-all checkbox, and a new "Discard all" toolbar action re-runs status on the host before acting. It clears only the working tree (the index is untouched) and refuses outright when the status stream was truncated instead of silently discarding a prefix. A truncated list offers "Expand all" (up to 10k changes) that stays complete across polls (#60)
- **Publish a branch that has no upstream**: when the remote branch does not exist yet, the push button becomes "Publish" — a single `git push -u <remote> HEAD` creates the branch and sets its upstream, no terminal needed. Detached HEAD and branches without commits are rejected with an explicit reason, and the action never carries `--force` (#63)
- **Folding only when the panel is both narrow and short**: width ≤620px switches to the single-column drill-down layout; folding the commit editor and hiding change / commit times needs width ≤620 **and** height ≤520. Narrowing the panel with the right sidebar open, or on a large phone, keeps the full editor and timestamps as long as the height allows; on a narrow-but-tall panel the times move to a second row and the AI entry stays on the folded bar (#66)
- **UI polish**: the row discard action uses the shared trash icon (the arrow read as refresh), disabled controls now show hover tips and dismiss them on the first touch, compact sub-tabs use short labels (Git / Changes / Files), and the A−/A/A+ font size moved into host config so it survives across sessions (#61)
- **HTML preview now loads relative styles and scripts**: inside the sandboxed iframe the preview reads same-directory css / js through document-relative paths and inlines them, so design mockups are no longer unstyled HTML. Caps are 4 MiB per asset, 32 MiB per pack and 64 assets; any failure falls back to the raw bytes with the sandbox unchanged (#67)
- **Floating refresh button in file browse**: a refresh entry sits at the top-right of the directory tree and re-reads the current directory; a response for the previous directory can no longer overwrite the new list while a refresh is in flight (#74)
- **HTML preview no longer freezes the panel**: the interactive iframe loads from a `blob:` URL, which Chromium gives its own renderer process — the same 1.25 MB report used to stall the whole GUI for about 12 seconds (12,064 ms of parent-page freeze, now 32 ms). A loading mask covers the preview area while it renders and fades out once the page reports itself ready (#75)
- **The fullscreen reader reuses the rendered preview**: the enlarge action restyles the already-rendering preview into a fullscreen card instead of rebuilding the iframe — page scripts do not re-run, and the code view keeps its scroll position and find state. A browser-fullscreen toggle appears to the left of the close control (#75)
- **Waiting on a heavy page is now predictable, exitable and avoidable**: past four seconds the loading mask stops blocking clicks, counts the wait and offers "Stop rendering" to drop straight back to the source view; a document with more than 512 KiB of inline script is confirmed in a dialog before its frame is mounted (cancel / render anyway); on a local instance the dialog also offers "Open in the system browser", while a remote instance explains that the file lives on the remote machine and can only be rendered inline (#76)
- **Fixes**: AI commit messages on OpenCode routes always failed with 400 `MissingSessionID` — the session id is now sent only when the provider name contains OpenCode (case-insensitive), other routes no longer carry the metadata, and the failure banner gained a close button (#71); commit failures are localized and the error banner centers single-line text vertically; loading indicators use the platform's `StateDot` animation, so the hand-drawn ring no longer shows a seam
- **Internal**: release notes are archived for stable versions only (`docs/releases/`), a pre-release page is written but not committed, stable notes compare against the previous stable tag, and stable install lists npm plus the asset while pre-releases list the asset alone — all checked per version by `release-notes.test.mjs`; README gained an acknowledgements section (#73)
