## 主要变更

- **HTML 预览不再冻结面板**：交互预览改在独立渲染进程中运行——同一份 1.25 MB 报告以前会把整个界面冻住约 12 秒，现在面板始终保持响应（32 ms）；渲染期间盖一层遮罩，等太久可直接「停止渲染」回到源码，内联脚本特别大的页面在挂载前还会先问一次，本地实例可以选择交给系统浏览器打开。预览同时会把文档相对的 css / js 内联进来，设计稿不再是无样式的裸 HTML（#67、#75、#76）
- **全屏阅读器不再重跑页面**：全屏只是把已渲染的预览换成放大样式，页面脚本不重跑，代码视图的滚动位置与查找状态也不再丢失；标题栏新增浏览器全屏开关（#75）
- **变更列表支持批量操作**：暂存 / 变更 / 未跟踪三组各带全选框，新增「放弃全部」（只清工作区、不动暂存区，状态流被截断时直接拒绝），列表被截断时可一键展开；远程分支还不存在的仓库可直接「发布」建分支并设置上游（#60、#63）
- **面板只在真正局促时才折叠**：布局改按宽度与高度综合判定——打开右侧边栏把面板压窄、或大屏手机上，只要高度够就保留完整提交编辑器与时间；同期打磨还有统一的垃圾桶图标、禁用按钮也能弹提示、紧凑子页签短标签、面板字号跨会话保持（#61、#66）
- **文件浏览可随时刷新**：目录树右上角常驻刷新入口，刷新期间旧目录的响应不会再覆盖新列表（#74）
- **修复**：AI 生成提交信息在 OpenCode 路由上固定报 400 `MissingSessionID`，且失败横幅新增关闭按钮（#71）；提交失败文案改为本地化、错误横幅单行居中；加载指示换成平台 `StateDot` 动效，自绘圆环不再露接缝

## English

- **HTML previews no longer freeze the panel**: the interactive preview runs in a renderer of its own — the same 1.25 MB report used to stall the whole interface for about 12 seconds and now costs 32 ms. A mask covers the preview while it renders, an over-long wait can be stopped straight back to the source, a document with very large inline scripts is confirmed before it is mounted, and a local instance can hand it to the system browser. Relative css / js is inlined as well, so design mockups are no longer unstyled HTML (#67, #75, #76)
- **The fullscreen reader stops re-running the page**: fullscreen only restyles the preview that is already rendering, so page scripts do not run again and the code view keeps its scroll position and find state; the title bar gains a browser-fullscreen toggle (#75)
- **Batch actions on the changes list**: the staged / changes / untracked groups each carry a select-all checkbox, "Discard all" clears only the working tree (and refuses outright when the status stream was truncated), and a truncated list expands in one click; a branch with no upstream can now be published from the panel in one action (#60, #63)
- **The panel only folds when it is genuinely cramped**: the layout rule judges width and height together, so squeezing the panel with the right sidebar open — or using a large phone — keeps the full commit editor and timestamps as long as the height allows. Alongside it: a unified trash icon, hover tips on disabled controls, short labels in compact tabs, and font size that persists across sessions (#61, #66)
- **File browse can refresh on demand**: a refresh entry sits at the top-right of the tree, and a stale directory response can no longer overwrite a newer list (#74)
- **Fixes**: AI commit messages on OpenCode routes always failed with 400 `MissingSessionID`, and the failure banner can now be dismissed (#71); commit failures are localized and the error banner centers single-line text; loading indicators use the platform's `StateDot` animation, so the hand-drawn ring no longer shows a seam
