## 主要变更

- **HTML 预览改在独立渲染进程里跑**：交互预览经 `blob:` 文档交给单独的渲染进程，同一份 1.25 MB 报告从「父页面冻结 12,064 ms」降到 32 ms；页面脚本默认执行，工具栏 `JS` 可随时切回不执行脚本的静态预览（#75）
- **重页面的等待现在可预期、可退出、可绕开**：渲染遮罩 4 秒后放行点击并显示已等待秒数，给出「停止渲染」直接回到源码视图；内联脚本超过 512 KiB 的页面在挂载前先用弹窗问一次（取消 / 仍然渲染）；本地实例还能选「在系统浏览器中打开」，远程实例则说明文件在远端、只能内嵌渲染（#76）
- **全屏阅读器复用已渲染的预览**：打开、关闭都不重建 iframe——不重跑页面脚本，代码视图的滚动位置与查找状态也不再丢失；标题栏新增浏览器全屏开关（#75）
- **文件浏览增加悬浮刷新按钮**：目录树与当前预览可随时重新读取，顺手修掉刷新期间旧响应覆盖新列表的竞态（#74）
- **面板只在真正局促时才折叠**：布局判据从「窄」改为宽度与高度综合判定，打开右侧边栏把面板压窄、或大屏手机上，只要高度够就保留完整提交编辑器与时间；折叠条上保留「AI」入口（#66、#72）
- **变更列表与提交信息**：按目录 / 未暂存整组勾选，列表被截断时可一键展开、也可「放弃全部」（#60）；没有远程分支时可以直接发布分支，不必再去终端（#63）；AI 生成提交信息补上会话标识，失败提示可关闭（#71）
- **修复**：提交失败文案改为本地化、错误横幅单行垂直居中；加载指示统一用平台的 `StateDot` 动效，自绘的圆环不再露接缝；HTML 预览会把相对的 css / js 内联进文档，设计稿这类引用能正常出样式（#67）
- **内部**：发布正文只归档正式版，发布模板区分正式版与预发布的安装渠道与对比基线

## English

- **HTML previews now run in a renderer of their own**: the interactive preview hands the document to a separate renderer process through a `blob:` URL — the same 1.25 MB report went from freezing the parent for 12,064 ms to 32 ms; page scripts run by default, and the toolbar's `JS` toggle switches back to a static preview that runs none (#75)
- **Waiting on a heavy page is now predictable, exitable and avoidable**: past four seconds the loading mask stops blocking clicks, counts the wait and offers "Stop rendering" to drop straight back to the source view; a document with more than 512 KiB of inline script is confirmed in a dialog before its frame is mounted (cancel / render anyway); on a local instance the dialog also offers "Open in the system browser", while a remote instance explains that the file lives on the remote machine and can only be rendered inline (#76)
- **The fullscreen reader reuses the preview that is already rendered**: opening and closing it no longer rebuilds the iframe, so page scripts do not run again and the code view keeps its scroll position and find state; the title bar gains a browser-fullscreen toggle (#75)
- **The file browser gains a hover refresh button**: the tree and the current preview can be re-read at any time, and a refresh race — a stale directory response overwriting a newer list — is fixed alongside it (#74)
- **The panel only folds when it is genuinely cramped**: the layout rule now judges width and height together, so squeezing the panel with the right sidebar open, or using a large phone, keeps the full commit editor and timestamps as long as the height allows; the folded bar keeps its "AI" entry (#66, #72)
- **Changes list and commit message**: select whole groups (a directory, or everything unstaged), expand a truncated list in one click and "discard all" (both #60); publish a branch when no remote branch exists yet instead of dropping to a terminal (#63); AI-generated commit messages now carry the session id, and a failed request can be dismissed (#71)
- **Fixes**: commit failures are localized and the error banner centers single-line text vertically; loading indicators use the platform's `StateDot` animation, so the hand-drawn ring no longer shows a seam; relative css / js is inlined into HTML previews, so design mockups referencing stylesheets render styled (#67)
- **Internal**: release notes are archived for stable versions only, and the release template now separates stable and pre-release install channels and comparison baselines

- `npm run check` green: lint + typecheck + **610** unit tests + **20** e2e runners
- Confirm before rendering a heavy page: `htmlHeavyAsks` / `htmlHeavyKeptSource` / `htmlHeavyAsksAgain` — cancelling is not an approval, so mounting the frame early or treating cancel as consent turns them red
