## 主要变更

- **批量暂存选中文件**：变更记录页工具栏新增「暂存选中的更改」按钮，勾选多个文件后一键暂存——此前只能逐行点「+」或整仓「全部暂存」。按钮只作用于勾选的工作区改动，未勾选的文件不受影响；没有任何可暂存的勾选时自动禁用（#82）

## 安装

```bash
# 正式版（npm）
dsh plugin --profile web add @xbzbing/dsh-git-panel@1.9.1

# 同一版本的 GitHub Release 附件
dsh plugin --profile web add https://github.com/xbzbing/dsh-git-panel/releases/download/v1.9.1/xbzbing-dsh-git-panel-1.9.1.tgz
```

## 验证

- `npm run check` 全绿：typecheck + 664 单测 + 22 个 e2e runner + 产物一致性
- 新增单测锁「暂存区侧（`:s`）勾选不参与批量暂存、同路径双侧勾选只暂存一次」：把目标解析改成两侧都收后该用例转红
- 新增 e2e 场景锁请求范围：发出的 `stage` 动作 deepEqual 恰为勾选路径（去重、排序），并覆盖「暂存成功后快照回灌、勾选修剪、按钮回到禁用」的完整回路

## English

- **Stage the selected files**: the Changes toolbar gains a "Stage selected changes" button — checking several files used to mean clicking each row's "+" or staging the whole work tree. It stages exactly the checked working-tree changes and leaves unchecked files untouched, and stays disabled while nothing stageable is picked (#82)

## Install

```bash
# Stable (npm)
dsh plugin --profile web add @xbzbing/dsh-git-panel@1.9.1

# The same version as a GitHub Release asset
dsh plugin --profile web add https://github.com/xbzbing/dsh-git-panel/releases/download/v1.9.1/xbzbing-dsh-git-panel-1.9.1.tgz
```

## Verification

- `npm run check` green: typecheck + 664 unit tests + 22 e2e runners + built-artifact consistency
- New unit tests lock "index-side (`:s`) picks never widen the batch and a path picked on both sides stages once": they turn red if the target resolution starts accepting both sides
- New e2e scenario pins the request scope: the emitted `stage` action deepEquals exactly the checked paths (deduped, sorted), and walks the full loop of snapshot re-accept → selection prune → button back to disabled
