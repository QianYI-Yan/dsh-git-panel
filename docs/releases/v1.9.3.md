## 主要变更

- **侧边栏提交备注框恢复完整高度**：右侧栏 stacked 档的提交信息框不再被压到一行半，与面板 tab 档一致显示完整编辑区（约 72px，三行可读）；只有手机（紧凑）档仍按需压缩，把高度留给变更列表（#86）

## 安装

```bash
# 正式版（npm）
dsh plugin --profile web add @xbzbing/dsh-git-panel@1.9.3

# 同一版本的 GitHub Release 附件
dsh plugin --profile web add https://github.com/xbzbing/dsh-git-panel/releases/download/v1.9.3/xbzbing-dsh-git-panel-1.9.3.tgz
```

## 验证

- `npm run check` 全绿：typecheck + 664 单测 + 22 个 e2e runner + 产物一致性
- stacked 高度回归（#86）：e2e 量测侧栏变更页输入框的计算高度，要求 min-height=72 且实际高度 ≥72；把压缩规则放回 stacked 即转红
- compact 压缩回归：同一批断言要求紧凑档 min-height=48，删掉 layout.ts 的紧凑规则即转红

[完整变更记录 v1.9.2...v1.9.3](https://github.com/xbzbing/dsh-git-panel/compare/v1.9.2...v1.9.3)

## English

- **The sidebar commit box gets its full height back**: in the right-sidebar stacked layout the commit message field no longer compresses to a line and a half — it shows the full editor (~72px, three readable lines) like the panel tab layout, while only the phone's compact layout still compresses it to give the change list the room (#86)

## Install

```bash
# Stable (npm)
dsh plugin --profile web add @xbzbing/dsh-git-panel@1.9.3

# The same version as a GitHub Release asset
dsh plugin --profile web add https://github.com/xbzbing/dsh-git-panel/releases/download/v1.9.3/xbzbing-dsh-git-panel-1.9.3.tgz
```

## Verification

- `npm run check` green: typecheck + 664 unit tests + 22 e2e runners + built-artifact consistency
- Stacked-height regression (#86): an e2e measures the computed height of the sidebar changes input — min-height must be 72 and the rendered height at least 72; putting the compression rule back on stacked turns it red
- Compact compression regression: the same run requires min-height 48 on the compact layout; dropping the rule in layout.ts turns it red
