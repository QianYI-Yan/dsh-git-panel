## 主要变更

- **多仓库切换**：面板会自动识别工作区里的多份检出——仓库自身的 worktree（`git worktree list`，如 `.agents/worktrees/<分支>`）以及子目录里各自独立的仓库；仓库列表挂在分支树所在那一面的顶部，切换后总览、变更记录与提交都作用于所选仓库，输入框标记同步跟随（#83）
- **文件浏览根跟随 Git 切换**：目录树列顶部的状态栏显示浏览根路径，候选根多于一时点击打开下拉（跟随 Git 切换 / 项目根 / 各仓库根 / 复制路径），可当场改选；「文件浏览跟随 Git 切换」详情页配置只作为各会话的默认值，改选一直保持到再次改选或修改配置（#83）
- **探测开关**：详情页「探测 worktrees and 子仓库」可整体关闭目录扫描与 worktree 识别，列表只保留工作区主仓库，保存后立即生效（#83）
- **配置页重设计**：无框重排、分区头加图标 chip 与悬停药丸、分区色引导线；配置项按标题 / 控件 / 说明分组，分组节点缩进对齐层级（#83）
- **窄屏多仓库**：compact 档的仓库列表并入「按分支筛选」抽屉与底部弹层，不占独立页签；切换仓库留在当前页、选中后存储库区块自动收起（#83）
- **切换在途保护**：切换仓库时旧内容整体压暗且不可操作（inert），标签栏显示「正在切换…」，新快照到达后一次性替换；旧快照上的暂存 / 放弃等写操作不再误落到新仓库（#83）
- **插件图标**：三处线与节点的连接改为平头直连，去掉圆头端点留下的内凹；分支改用半径 11 的圆弧转弯，弯折处线宽保持不变
- **修复**：worktree 列表改用 `porcelain -z` 解析（旧 git 回落换行格式）、已认领的 worktree 不再占用子仓库扫描名额、文件属性弹窗按浏览根拼绝对路径、子页签选中项切换时标签栏不再伸缩、全屏失败落可见提示（#83）
- **内部**：构建脚本在 Windows 上直接调用 tsc；竞态注入测试的 `.git` 路径匹配改用 `path.sep`，修复 Windows 上注入不触发；升级 eslint 10 / typescript 6.0.3 / esbuild 0.28.2

## English

- **Multiple repositories**: the panel detects every checkout in the workspace — the repository's worktrees (`git worktree list`, e.g. `.agents/worktrees/<branch>`) and independent repositories in subdirectories; the list docks at the top of whichever surface holds the branch tree, and after a switch the overview, changes and commits all act on the picked repository, with the input-bar marker following (#83)
- **File browser follows Git switches**: the status bar atop the tree column shows the browse root; with several candidates a click opens the list (Follow Git switches / Project root / each repository root / Copy path) and can be overridden on the spot; "Files browser follows Git switches" on the detail page is only each session's default, and an override holds until the next pick or a change of the setting (#83)
- **Detection switch**: "Detect worktrees and nested repositories" on the detail page turns directory scanning and worktree discovery off entirely; the list keeps the workspace's main repository, applied immediately (#83)
- **Config page redesign**: frameless re-layout, icon chips on section headers with hover pills, and section-coloured guide rails; settings are grouped into title / control / description, with group nodes indented to their hierarchy level (#83)
- **Repositories on a narrow panel**: on the compact layout the repository list joins the branch-filter drawer and the bottom sheet instead of taking a tab of its own; a switch keeps you on the current page and the picked row collapses the section again (#83)
- **Switch guard**: while a switch is in flight the previous content dims and goes inert, the tab bar says "Switching…", and the new sample replaces it in one step; write operations such as stage / discard no longer land in the newly picked repository by accident (#83)
- **Plugin icon**: the three line-to-node joints now run straight through with butt ends, removing the inward notches the round caps left; the branch turns on radius-11 arcs so the stroke keeps its full width through each bend
- **Fixes**: the worktree list parses `porcelain -z` (falling back to the line format on older git), a claimed worktree no longer occupies a nested-repository scan slot, the file-properties dialog builds its absolute path from the browse root, the tab-bar label no longer resizes when the selection moves, and a failed fullscreen open surfaces a visible notice (#83)
- **Internal**: the build script invokes tsc directly on Windows; the race-injection tests match the `.git` path with `path.sep`, fixing injections that never fired on Windows; upgrade eslint 10 / typescript 6.0.3 / esbuild 0.28.2
